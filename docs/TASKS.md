## 贡献指南

### 如何添加任务

1. 在对应部分添加任务
2. 使用 `- [ ]` 格式
3. 添加优先级标签
4. 说明任务详情

### 如何标记完成

1. 将 `- [ ]` 改为 `- [x]`
2. 添加完成日期
3. 移动到"已完成"部分

### 任务格式

```markdown
- [ ] 任务描述
  - 优先级：P0/P1/P2/P3
  - 预计时间：X 天
  - 负责人：XXX
  - 截止日期：YYYY-MM-DD
```
