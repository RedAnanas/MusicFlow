# 共享音频播放器

操作台与发现音乐使用同一个 `MusicPlayer.vue` 组件，提供播放／暂停、上一首／下一首、进度拖动、音量、频谱和歌词。

- 操作台点击文件行的“播放”，按当前文件夹、搜索及格式筛选后的完整列表切歌，不受分页限制。
- 发现音乐保留原有试听按钮、双击播放与搜索结果切歌。
- 歌词来自发现音乐的歌词接口或本地文件的内嵌歌词；没有歌词时显示“暂无歌词”。
- 空格控制播放／暂停，Alt＋方向键切歌；输入框、按钮和可编辑区域不拦截键盘输入。
- 列表末尾不循环；当前曲目被筛选排除后不自动跳到其他歌曲。离开页面停止播放并释放音频资源。
- 移动端沿用发现音乐的紧凑播放器；桌面显示音量和频谱。

本地播放接口为 `GET/HEAD /api/files/{file_id}/stream`，仅允许缓存中登记、且仍位于操作台音乐来源内的音频文件。支持单段字节范围请求，供浏览器拖动进度；非法或多段范围请求返回 416。歌词接口 `GET /api/files/{file_id}/lyrics` 仅返回歌词，不携带封面。

播放使用浏览器解码，不自动转码，不创建转换或上传任务。不支持的格式或编码会提示播放失败。
