# 配置备份、恢复与迁移

入口：“系统设置 → 配置备份与迁移”。

## 导出范围

导出单个 UTF-8 JSON 文件，包含格式版本、应用版本、来源平台和以下配置：

- 通用音乐路径、转换并发、FFmpeg 线程和文件稳定等待时间。
- 转换方案及原 ID、命名模板、标签与封面策略、Apple Music 上传方式。
- 监控输入目录、扫描设置、投递目标与关联方案。
- 操作台音乐来源、资料库对账媒体库路径、双库监控关联和 storefront。
- 不含账号凭据的 musicdl 服务地址。

不包含歌曲文件、任务历史、SQLite 数据库、索引、Apple 资料库快照、授权、服务令牌、加密密钥、官方算法文件或浏览器主题。Apple 授权仍使用专用加密导入入口。Docker 卷挂载、环境变量和服务令牌需要在目标环境单独配置。

## 恢复过程

1. 在原环境导出配置，妥善保管备份文件。
2. 在目标环境选择该文件，查看配置数量和路径可访问性。
3. 停用目标环境的所有监控，并等待转换、下载和文件导入任务结束。
4. 确认替换配置。系统先将旧配置保存至配置目录的 `configuration-backups/<备份ID>.json`，然后恢复七类配置；写入失败会尝试回滚原文件。预览后若目标配置变化，必须重新预览。
5. 导入后可直接下载导入前备份。核对路径、挂载、musicdl 地址和转换方案，再按需手动启用监控。导入不会自动启用监控、创建转换或上传任务。

路径按原字符串保留，不自动转换 Windows/Linux 路径。不存在的路径允许恢复并给出提示，需调整目标挂载或在对应设置页面修改。并发参数需重启服务后生效。通用设置已持久化到 `settings.json`，后续重启不再丢失。

配置包上限 1 MiB，仅接受 MusicFlow 格式版本 1。方案及监控 ID 保留，检查关联完整性；不支持任意 ZIP 解压或指定服务端写入文件名。

## 接口

- `GET /api/system/configuration/export`：导出当前配置。
- `POST /api/system/configuration/preview`：上传 `file`，校验并预览，不写入。
- `POST /api/system/configuration/import`：上传 `file` 和预览返回的 `current_revision`，确认恢复。
- `GET /api/system/configuration/backups/{backup_id}`：下载该次恢复前自动保存的配置包。
